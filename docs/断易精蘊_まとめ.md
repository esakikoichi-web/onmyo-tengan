# 『断易精蘊』まとめ

九鬼盛隆（碩果子）著／八幡書店（活字版。平成12年初版、全823頁）

> 青龍孔一（江﨑孔一）さんの実占用ノートです。『周易講義』『周易裏街道』のまとめと同じ実占ノートの形にしてあります。ただし本書は周易ではなく**断易（五行易・納甲易）**の書です。そのため「六十四卦ごと」ではなく、次の構成にしました。
> - **用神と五類の象意**
> - **機関（旺衰・生剋・合冲・空亡など）の読み方**
> - **四賦（天玄・通玄・砕金・千金）の即断句**
> - **応期断則27則**
> - **断法各論24部門**（部門ごとに【用神】【占断の目安】【要点】【九鬼説】【占験】）
>
> 「★」は、九鬼が特に強調している点か、通説と違う九鬼独自の説です。
> 各部門の【占断の目安】は、本文の断則を実占向けに短く引き直した**まとめ役による要約**です。【要点】【九鬼説】【占験】は本文に拠っています。

## 0. 本書について

- **著者**：九鬼盛隆（号は碩果子）。東京牛込若松町の人。
  - 根本通明を「吾先師」と呼ぶ門人です。『周易講義』の纂修者でもあります。
  - 周易（経学科）と断易の両方を門人に講じていました。
- **成り立ち**
  - 大正7年に凡例を書き、謄写版で4回刷りました。活字版の底本は1932年の謄写版全4冊です。
  - 入門者に原稿を順に回して筆写させたのが始まりで、非売本として篤志者に頒けていました。
- **研究の経歴**（本人の告白）
  1. 『断易天機』を読んだが、断片的で偽作が多く、使えないと判断した。
  2. 『卜筮正宗』所収の劉伯温『黄金策』に傾倒した。周易では説明のつかない支那名士の占断が、この法で解けた。
  3. 次の書を通読した。
     - 京氏易伝、易洞林、易冒、天玄賦、卜筮元亀、易林補遺、火珠林
     - 増刪卜易、五行占、易伝略集、海底眼、易隠、卜筮全書
  4. ★古書の評価
     - 5割は京房の妄説に拠り、3割は周易と混ぜた雑種。理拠ある古義は2割しかない。
     - 理論は劉伯温『黄金策』の「千金賦」、占断の妙は野鶴（『増刪卜易』）の占験が群を抜く。
  5. 以後は実占で自ら確かめ、「宇宙間無二の予知術」と確信するに至った。
- **本書の立場**
  - ★**周易は道徳が本旨**で、占筮には間接的にしか使えない。**本易占は陰陽の至微を直接に断法とする**ので、効き目に天と淵ほどの差がある。
  - ★祖師は戦国時代の**鬼谷子**（王詡）。伏羲以来の陰陽五行・八卦・干支を材料に、断法を組み立てた「巨匠」とする。
  - ★漢の**京房**が神煞を持ち込み、鬼谷の真伝を乱した。明の劉伯温がこれを正した。
  - ★「断易」という名は明末以来の通称で古義ではなく、九鬼自身は好まない。通りがよいので書名に用いた。
  - 秘伝・奥伝もすべて公開している。総論は口語、断法は文語。
- **研修法**（凡例）
  - 総論を精読したうえで、特に**機関の応用法**を研究する。
  - 各論は本文とあわせて**占験例を味わう**のが最短の道。占験例は本文の注釈にあたる。
- **全体の構成**

## 1. 占断全般の心得

### 1-1 至誠感通（臨占要鑑）
- ★**神を人格視しない**
  - 高島呑象の「神人感通」説は批判の対象。「術が未熟でも、神が自分の判断力に合わせて教えてくれる」と考えるのは誤り。
  - 九鬼の説では、卦は**陰陽の働きを映す秘鏡**。占者が雑念を払い無我に至った刹那、大宇宙の霊気と一つになり、その答えが卦に映る。
  - 卦は誰が立てても当たる。ただし**正しい断法で読まなければ必中しない**。
- **筮法は形、至誠は心**
  - 温度計の喩え：沸点は湯の中でなく湯気の上で、氷点は固い氷の中でなく溶けかけた水の中で測れる。同じように、無我から知覚が生じる刹那が至誠の最も熾烈な時で、この機に策を分け銭を擲つ。
- **筮法の評価**

  | 筮法 | 九鬼の評 |
  |---|---|
  | 三変筮（略筮） | 簡易だが理浅く、変爻を後から求めるのが不自然。清以前の支那にすでにある |
  | 六変筮（中筮） | 変爻が自然に出るのが長所だが、理拠が浅い |
  | 九変筮 | 煩瑣で附会が多い。邦人の創作か |
  | 十八変筮（本筮） | 朱子が大成。繋辞伝と合わず、孔門の筮法ではない |
  | 三十六変筮（復古筮法） | 毛奇齢・戸崎允明・皆川淇園が構想し、根本通明が制定。大伝と一致するが複雑で、現代に合わない |
  | 擲銭法 | 鬼谷子の創定。簡易で実用的 |

  - ★実験上の的中順：**擲銭法が1位**、三変筮が2位、六変と十八変はほぼ同じ、九変がその次。三十六変は数が少ないが、大事件を2回的中させた。
  - 結論として、**簡易な筮法で十分に至誠は通じる**。九鬼はさらに独自の筮具「**神蓍**」を制定した（高津常山が神蓍で36件を占い、九鬼が結果を知らずに断じて全件的中）。
- **修養三慎**
  1. 常に心を高潔に保ち、良心に背かない。過ちはその場で懺悔する。
  2. 筮の前に斎戒する。重大事なら数日、小事でも数刻の心斎をする。
  3. 問筮の時は**必ず中ると確信**する。一点でも疑いがあれば外れる。
- **問筮六戒**
  1. **用神が定まらないうちは問わない**（最も多い過失）。
  2. 誠意のない人のためには問わない（試し、ついで、事実を隠して占者の口ぶりを探る、など）。
  3. 不義・非倫・私欲のことは問わない。
  4. **一卦で幾つもの事を問わない**（求財も身命も病気も、はだめ。分けて占う）。
  5. 心身が不快な時は問わない。
  6. 事柄が不明なこと、結果が既に見えていることは問わない。
- **筮儀**：斎戒沐浴して閑室に端座し、「臨占祝詞」（玄気絪縕、周流六虚……）を読み、深呼吸して精神を統一し、無我に入ってから筮具を執る。神蓍は丹田に気を満たし、一刀両断のように一気に下ろす。

### 1-2 再筮と分占
- ★**再筮は必ずしも不可ではない**
  - 以前は蒙卦「初筮告、再三瀆」を信じて再筮を戒めていた。
  - 『増刪卜易』の野鶴の説に従い、判断に迷う卦を**日を隔てて再占**すると、前後の卦が連続して明瞭になり、的中した。以来一度も外れがない。
  - 蒙の辞は、童蒙が疑心から師に問い直すことへの戒め。至誠で問い直すなら初筮と同じ。
  - 注意点：
    - 未熟ゆえの安易な再筮は慎む。
    - なるべく日を隔てる（理論上の禁忌ではなく、本心への遠慮）。
    - 門外には発表しない。
  - 野鶴を批判した王維徳（『卜筮正宗』）は、野鶴の説の多くを剽窃しているとも言う。
- ★**分占が原則**
  - 一卦で本人と父兄妻子の禍福を併せて断ずるのは理に合わない。例：父母が旺動すれば子孫を剋すことになるが、父母の丈夫な家の子は皆病弱だとでもいうのか。
  - 家宅の章では、一卦で家中の変異を兼断する俗法をわざと実演してみせ、そのうえで否定している（「売名術技の徒の所業」）。
- ★**占題を明確に告げる**
  - 易は巫覡と違い、過去を告げない（天気を占っても昨日の晴雨は出ない）。
  - 例：今いる子の生死を問うて「子なし」と出たら、「今後早死にする子はない」の意であることがある。

### 1-3 卦の応じ方の癖
- ★**此を占い彼に応ずる**
  - 父兄妻子を占って、世爻に自分の大凶や大吉が出ることがある。
  - 遠い将来を占って近いうちの小変が出たり、一年を占って翌年に応じたりもする。
  - 占題に通じない卦は、強いて断じずに**再問**する。
- ★**占題外でも重大事は出る**：売り時を占って火災と本人の死が出た例がある（求財の占験）。
- ★**暦の一日差**
  - 中央天文台の暦の日干支に一日のずれがあると九鬼は考えた。出産日が一日ずれた例などがある。
  - 日の応期は**前後一日の余裕**を見ておく。

## 2. 卦をまたいで使える読法の秘訣

| 秘訣 | 内容 |
|---|---|
| ★**用神一つを定めて見る** | 本易の要は、唯一の用神に日・月・動爻がどう関わるかを見ること。飛神に五類が揃っているのに毎爻の伏神まで判断に混ぜる断易派のやり方は、「正宗の名刀で果物を切る」ようなもの |
| ★**太過は損し、不及は益す**（千金賦） | 衰弱した病人の卦で、用神が旺相し、日月を帯び、回頭生を受け、動爻にも生じられるのは**強すぎ＝必死の兆**。剋が一つ加わるか休囚なら中庸で、快癒する。逆に安静休囚で絶に入っていても、元神が発動して生ずれば**絶処逢生**で必ず治る |
| ★**極旺・大剛は傾く** | 八十過ぎの翁の卦が全盛の象だったのは「日没前の燈の最後の光」で、壬戌日に死去。連日の大雨の卦で父母が日月を帯びて回頭生に化したのも「物窮まれば変ず」で、その日のうちに快晴になった |
| **生扶拱合は時雨、剋害刑冲は秋霜** | 生＝日月動爻が用を生ず。扶＝日月が同類で前の支（子の用に亥の日）。拱＝後の支（亥の用に子の日）。合＝支合・三合・六合卦。剋冲は重く、刑害は軽い。静爻からの剋冲は傷とならない |
| **日辰は六爻の主宰、月建は万卦の提綱** | 日辰は効力を失わない。月建は月内に限られるが、月内は日辰と同権。月破は日冲と違い、破壊のみで専純峻烈 |
| ★**日が爻を傷れば真に禍、爻が日を傷つけても名ばかり** | 日月（天象自然）に剋されれば、空・伏・墓に逃げても逃れられない。動爻が日月を剋すのは天に石を投げるようなもの |
| **動は始め、変は終り** | 動爻が他に及ぼす働きが始め、化爻から受ける結果が終り。回頭剋・回頭冲の「交争」を最も怕れる |
| **好変・壊変** | 生合・進神・長生に化すれば好変。剋冲・退神・墓絶に化すれば壊変 |
| **物来就我・我去尋物** | 用爻が動いて世を剋・冲・生・合すれば、物が来て我に就く（剋が最も速く、冲が次、生合は緩やか）。世が動いて用を追えば我が去って尋ねることになり、成りにくい |
| **貪生忘剋・貪合忘剋** | 忌神と元神が共に動くと、忌神は元神を生ずることに気を取られて用神を剋すことを忘れ、元神は倍の力で用神を生ず（接続の相生）。合を貪って刑剋を忘れるのも同じ |
| **合住（合絆）** | 動爻が日月・動爻と合すると、楽を貪って働きを忘れる。冲の日に解ける |
| **暗動** | 旺相の静爻を日辰が冲すれば暗動。休囚なら冲散（日破）。暗動は隠微で「福来たるも知らず、禍来たるも覚えず」。応期は合の日 |
| **冲中逢合・合処逢冲** | 冲の中で合に逢えば成る。合の所で冲に逢えば破れる（ただし凶神の合が冲されれば吉、吉星なら凶） |
| ★**六合・六冲の互変は卦だけで断ず** | 六冲→六合、六合→六冲の変は、用神を見ずに卦変だけで成否を断じてよい。この4つの変態は応験が最も多い（婚姻・選挙・議院・興業の各章で繰り返し強調） |
| **空亡の有用・無用** | 旺相・動爻・生扶ある空は空とせず、出空・冲実・填実の時に応ず。月破を兼ねる空、無気で動かない空、春の土・夏の金・秋の木・冬の火・土用の水（時令に剋される）は**真空**で、永く無用 |

## 3. 組織と機関の早見（第1〜2篇）

### 3-1 総論の要点
- **太極**：★宋儒の「無極」説を退ける。易は数が本で、太極は零ではなく一。神道の天之御中主神を太極、高皇産霊神・神皇産霊神を陰陽にあてる。
- **運命**：天命（陽・精神・根幹）と修養（陰・肉体・枝葉）の合成。修養は天命の範囲を超えないが、その範囲内で伸縮できる（杉の木の喩え）。
- **河図と洛書**
  - 河図：生数の1〜5が気、成数の6〜10が形（生数に土の5を加えたもの）。左旋の相生を示し、天道・仁にあたる。十干は河図から出る。
  - 洛書：相剋・地道・義にあたる。十二支は洛書から出る。
  - ★世人は生の吉だけを知り、剋の用を知らない。九星術で生剋を乱用し、良縁を逃す例もある。
- **五行の本性**
  - ★五行を形質で説く（「木は燃料だから火を生む」など）のは子供騙し。本来は気（冷・熱・風・燥・湿）で説く。

  | 五行 | 本性 | 季・卦 |
  |---|---|---|
  | 木 | 伸出・開発・緩・向上・施行（触・冒） | 春・震巽 |
  | 火 | 炎熱・膨脹・騰升・乾燥・熔化 | 夏・離 |
  | 土 | 調和・包蔵・保育・節抑・厚重（吐） | 土用（特に夏の土用）・坤艮 |
  | 金 | 緊縮・杜絶・閉塞・更革・銷殺（禁） | 秋・兌乾 |
  | 水 | 冷清・低下・凝集・湿潤・任養（潤） | 冬・坎 |

  - 土用の酷暑・極寒は、土の性ではなく火・水の余勢を土が抑えているもの。
  - ★相生の「生ずる」は、生まれるの意と助けるの意を兼ねる。**我が他を生ずれば泄気**で、我が力を分けるので不利。
  - 相剋の「剋す」は、克つ・制する・利用するの意を兼ねる。剋す方が勝ち、剋される方が敗れる。
  - 比和は助け合うが、重なりすぎれば功を競い、純精を失う。
  - ★吉中に凶あり、凶中に吉あり。強すぎれば折れ、衰弱も一生を得れば活躍する。
- **十二支と十干**
  - 十干は気、十二支は形。日常の千態万状は地上の変化なので、**十二支のほうが用途が広い**。
  - 十二支の獣（子＝鼠など）は理由不明だが、実占で応験があるので従う。
- **八卦**
  - ★方位は必ず**後天**（説卦伝「乾西北之卦也」）を使う。先天方位（宋の陳摶・邵雍・朱子）を占断に使うのは断じて不可。
  - 爻の符号：重（○）＝老陽で変じる。交（×）＝老陰で変じる。単・拆＝少陽・少陰で変じない。
  - ★震を「長子」とするのは、長男に資格がなければ次男・三男から選んだ者が長子となる意。これを明らかにしたのは「吾先師根本通明先生」のみ、とする。
  - 第9章「卦象推広」で八卦ごとの天文・地理・人倫・時令・肢体・世態・器財・数量・色食・動植を列挙（天皇・内閣・逓信官・飛行器など、明治大正の事物も配当）。

### 3-4 十二運と四時の旺衰

  - ★実占で使うのは**長生・帝旺・墓・絶の4つだけ**。他の8運は生剋比和の理で断ずる。十二運をすべて同じように使う古書は、理が薄く応験もない。
  - 用い方は7通り：年・月・日・時の支、爻に帯ぶ支、化爻の支、伏神が出る時の飛神の支。
  - 自ら帯ぶもの：木の寅卯、火の巳午、金の申酉、水の亥子は臨官・帝旺。土には臨官・帝旺がなく、辰が自墓。日辰に臨官・帝旺が当たれば、季節を問わず旺とする。

  - 例外：巳日の土、巳に化す土は、旺相・扶助・大象が吉なら絶ではなく回頭生とみる。金が巳に化す、土が申に化すのも、剋ではなく長生を取る。
- **四時の旺衰**：時令と同じ＝旺、時令に生じられる＝相、時令に剋される＝死、時令を剋す＝囚、時令を生ず＝休（泄気）。旺相は活動力があり事が通じやすく、死囚休は行われにくい。ただし日月・動爻の生扶拱合、刑冲剋害で大きく変わる。

### 3-6 冲・合・刑・害・空
- **六冲**：子午・丑未・寅申・卯酉・辰戌・巳亥。
  - 月破
    - 旺相で生扶ある爻の月破は月内だけの傷で、月を過ぎれば有用。
    - 月破に空亡・休囚・日辰動爻の冲剋が重なれば**真破**で、終始無用。
    - 破爻の支の日は「実破」で月内でも有効。破の中の合は「合破」、合の中の破の値日は「填実」。真破は填実しても働かない（早枯れの草木は雨露を得ても蘇らない）。
  - 日冲
    - 旺相の静爻→暗動。休囚の静爻→日破。
    - 旺相の動爻→一時働きを失うが、合の日に働く。休囚の動爻→散。
    - 空亡の爻→冲実で有用。合を帯ぶ爻→冲開（成就・解散・応期）。
  - 卦の冲
    - 六冲卦：八純卦・天雷无妄・雷天大壮。
    - 反吟（卦の反吟は坎↔離・兌↔震・巽↔乾・艮↔坤、爻の反吟は巽↔坤のみ全爻）。
    - ★六冲卦は他に吉象がなければ事は成りにくい。ただし**官事・訴訟・出産は吉**。
    - 難事や凶象を帯びた爻は、化爻に冲されるとかえって難事が解ける。
- **六合**：子丑・寅亥・卯戌・辰酉・巳申・午未（日月の会と斗建の合から出る）。
  - **三合**：申子辰＝水局、亥卯未＝木局、寅午戌＝火局、巳酉丑＝金局（長生・帝旺・墓）。土局（淮南子）は研究の余地ありとして保留。
  - 干合（甲己など）は本易占ではほとんど使わない。
  - ★合は原則として吉。ただし**凶事の合は結んで解けない**。官事・訴訟・征戦・憂疑怪事に合は凶、**出産に合は難産**。
  - 合中帯剋（子丑・卯戌・巳申）：用が旺相なら合の吉、休囚なら剋の凶を取る。
  - 三合の応用
    - 官鬼の局は功名に吉、子孫の局は大凶。財占で財局＝財貨が庫に満ちる、子孫局＝利源が深い、兄弟局＝破財。
    - 応期：二爻動いて一爻静→静爻の値日。一支欠く→欠けた支の月日（虚一待用）。空→出空。墓→冲。絶→生。
- **三刑**：寅巳申（恃勢）、丑戌未（無恩）、子卯（無礼）、辰午酉亥（自刑）。
  - ★重く見すぎない。三支（自刑は同支）が卦・日月に揃って初めて成立する。静爻からの刑はほぼ無意味。
- **六害**（子未・丑午・寅巳・卯辰・申亥・酉戌）：★ほとんど応験がない。九鬼の経験でも、病人の死因に一度出ただけ。
- **空亡**：甲子旬は戌亥、甲戌旬は申酉、甲申旬は午未、甲午旬は辰巳、甲辰旬は寅卯、甲寅旬は子丑。
  - 我を益する爻の空は不利、我を害する爻の空は吉。
  - 古法「火空則発、土空則陥、金空則響、水空則流、木空則折」。
  - 久遠の事は歳の空、1〜2年は月の空、近事は日の空、数日の急事は時の空を用いる。**歳と日が最も有効**。

## 4. 用神の立て方と五類の象意（第28章）

### 4-1 世・応・爻位
- **世を用神とする**
  - 自分で自分の身上を占う時。本人から直接頼まれて代わりに占う時。
  - ★父母兄弟妻子から委託されて、その人の身上を占う時も世。ただし**自分の発意で他人を占う時は五類**を使う。手紙での依頼も同じ扱い。
  - 我が国・我が地域・我に利害ある事件や場所も世。
- **応を用神とする**
  - 五類にあてはまらない他人（面識はあっても親交のない人、高位でも国家の要路にない人）、敵国、仇人、医師、諸流の術士、彼地・彼所。
  - ★**争い・訴訟の相手は、近親でも応**。
- **爻位**
  - 上爻＝皇天・宗廟・神仏の霊位、五爻＝天皇・上皇・皇后・皇太后、四爻＝皇子・総理大臣・国務大臣。
  - 三爻・二爻・初爻に公職を配当する説は的確でない（九鬼が実験で応験を認めたのは上の3つだけ）。

### 4-2 五類の象意

| 五類 | 人倫 | 事物・その他 | 性情 |
|---|---|---|---|
| **父母** | 父母・祖父母・伯叔父母・舅姑・義父母・師長・主人・年長の同輩・乳母 | 天地・雨・宮室城壁宅舎・田園土地・船艦汽車電車航空機・衣服布・雨具甲冑帽子・文章書信電信・訴状証拠書類 | 諸星の頭領。★伏蔵・無力なら事に統体なし。辛労の神、子孫（福神）の忌神 |
| **官鬼** | 夫・夫の兄弟・夫の同輩・官人 | 官職・官庁・裁判所・雷・逆風・濃霧・電気・神仏・霊・妖魔・敵将・盗賊・病症・屍体・武器 | 普通は憂患の神。**官事功名では主星で吉**。★卦中に官鬼がないのは不吉（兄弟の破財を抑える者がいない）。静かに卦中にあるのを喜ぶ |
| **兄弟** | 兄弟姉妹・従兄弟・姉妹の夫・妻の兄弟・親友・同門・同業 | 風雲・争奪 | 財を破り功を奪う。子平の劫財。大福も大凶もなさない |

| **子孫** | 子・孫・女婿・甥・門人徒弟・忠臣良将・僧侶神官道士術士・弁護士・薬剤師・兵卒 | 六畜禽鳥・財源・酒肴・医薬・難を避ける地・太陽月星・順風好天 | 福徳神で憂患を解く。**功名官職では剥官の悪煞** |

- 五類は人倫だけでなく、八卦の象と同じように万般に推して使える。
- 父母の仇（官鬼）は子（子孫）が報い、その子はまた父母に剋される。五類の生剋は環のように循環する。

### 4-3 用神が両現・不現のとき
- **両現**：①旺相 ②動 ③世・卦身を帯ぶ ④日月臨む ⑤日冲・月破 ⑥空亡、の方を取る。
  - ★「月破や空亡の爻は無用だから取らない」という説は採らない。神機は異状のある所に出る。
  - ★『卜筮正宗』の「用神多現」（伏神や化爻まで数えて三つ四つ現ずとする）は笑うべき説。『五行易指南』は歯牙にもかけない。
- **不現**：①動爻に化出があれば化爻 ②なければ伏神。
  - 有用の伏神：併起、生起、冲去、提抜。
  - 無力の伏神：休囚で日月に剋される、旺相の飛神に圧住される、日辰で墓絶、飛神に出て墓絶、月破、空亡（旺相なら普通に扱う）。

各部門を【用神】【占断の目安】（まとめ役による要約）【要点】【九鬼説】【占験】の順に並べます。占験の卦は「本卦→之卦」で記します。

### (35) 気象
- 【用神】
  - 晴＝妻財、雨雪露霜＝父母、風雲＝兄弟、雷電・暴風雨・黒雲・濃霧・地震・不順＝官鬼、日月星辰・虹・順風＝子孫。
  - 大空＝応、大地＝世。
- 【占断の目安】
  - 財が動いて他故なければ晴。父母が動けば雨。
  - 晴を占って財が伏していれば子孫を見る。雨を占って父母が伏していれば官鬼を見る（元神が代わって応ず）。
- 【要点】
  - 財
    - 財が動いても子孫が弱ければ浮雲が残る。財と子孫が共に旺動すれば連日晴、日月の生扶もあれば大旱。
    - 財が官に化すれば前晴後曇。父母に化すれば陰晴定まらず。兄に化せば風が起こる。子孫に化せば一点の雲もない快晴。
  - 父母
    - 旺相でも動かなければまだ雨ではない。休囚なら決して降らない。
    - 父母と官鬼が共に動けば大雨・連雨。日月の生扶もあれば河川が氾濫する。
    - 兄弟・官鬼に化せば暴風雨（動が先、化が後。冬は吹雪）。子孫に化せば雨の後に晴・虹。
  - 兄弟が木で発動、または巽宮の兄の発動は大風。
  - 官鬼
    - 独発して進神に化せば、夏は大雷雨、冬は雹・霰。震宮なら雷鳴、離宮なら電光。
    - 官鬼が勾陳の世を剋冲すれば地震。
  - 綜合
    - 応が空なら旬内の晴雨は測りがたい。
    - 反吟なら晴雨が反覆する。財と官が共に動けば雲霧が多い。
    - 一年を占って、太歳が子孫なら順調、官鬼なら風水旱震の害。
- 【九鬼説】
  - ★古来の「水火の爻」「壬癸丙丁」「玄武朱雀」で晴雨を見る説は、一面の理に偏ったもの。世応と五類で用神を定める。
  - ★天気占は結果がすぐ分かるので、**日課として占い、外れたらその機因を熟察せよ**。占断の上達の最短路。
- 【占験】
  - 大壮→夬：財が日冲で暗動し、子孫が進神に化す→碧空の晴。
  - 小過→旅：上爻の父母が独発して回頭生。当日の辰刻に雲、巳刻に雷、未刻に雷雨と刻限まで的中。
  - 困→比：父母が日月を帯びて回頭生（大剛）だが、子孫が長生に化す→申刻に雲が開き亥刻に快晴（物窮まれば変ず）。
  - 鼎→睽：財局が父母を剋すが、父母は伏して空で剋を避けている→雨は止まず、出空の卯日に晴れた（前日の寅日はかえって大雨）。
  - 観→升：反吟→晴雨が連日反覆した。
  - 小過→革：乙卯日の雨と断じて外れ、立秋後の辛酉日に大雨→「神の示す所は厳。断者未通で誤る」。
  - 離→旅：酉日か卯日か決めかね、同日に再占して艮→謙。寅日に天変、卯日に雨、辰日に晴を的中。★再占が前卦の疑いも解いた例。

### (36) 国運
- 【用神】
  - 本宮＝国家全体。上爻＝宗廟・祖先神霊、五爻＝君主、四爻＝主務大臣、三爻＝府県知事、二爻＝在野の政党・国士、初爻＝万民。
  - 官鬼＝官庁・神仏・祟・災厄、父母＝文教・雨、兄弟＝破散・風、財＝国家経済・晴旱、子孫＝禍を払い福を守る。世＝我が国、応＝外国・敵国。
- 【占断の目安】
  - 本宮の五行の旺衰で国運の隆替を見る。太歳の生剋で一年の大勢を見る。
  - 吉祥泰平の象は、五類が皆静かで、財と子孫が旺相、官鬼が休囚・空亡、父母に気がある卦。
- 【要点】
  - 官鬼
    - 水は洪水、火は火災（内卦は近く外卦は遠い）、金は干戈・盗賊、土は悪疫、巽宮の木は大風。
    - 朱雀が世なら政争、応から剋すれば外交の難事。勾陳が世なら農事の憂い。
    - 螣蛇は怪異。乾宮なら天体、坤宮なら地滑り、震宮の上卦なら雷・下卦なら地震、離宮なら噴火。
  - 父母が四爻で旺動なら政令が行き届く。空伏なら朝令暮改。
  - 兄弟が世で旺動なら不景気。四爻に旺相なら、大臣に理財の能がない。
  - 子孫が五爻なら仁君、四爻なら賢相、二爻なら志士。
  - 財が子孫に化せば殖産が興り輸出が超過する。巳午の財が子孫に化せば夏の大旱。
- 【九鬼説】
  - ★古書の「父母＝国、歳星＝君、歳合＝皇后、月建＝大臣、日辰＝東宮」は採らない。卦中に現れない月建を大臣としたら、大臣は傷つかないことになる。
  - 子孫を東宮とするのは王家の占で用いる。
  - ★九鬼は一陽来復の日や歳首に、毎年国家の重大問題を占うのを例としていた。
- 【占験】（大正4年分を前年子月癸巳日に占う）
  - 皇室：升→大壮。五爻の亥水が旺静で月建に拱せられ、日冲で暗動。両財が動いて五爻を剋す（財来就我）→輸出超過・財政隆運を的中。
  - 天災地異：恒→坤。三陽爻が動くが、子孫が官鬼を剋し、父母は日冲散→水患の断則を破って無事平穏。
  - 国勢：豫→坤。応（外国）の子孫が独発して世の財を生合→連合国への軍需輸出で大収利。ただし世の財が休囚安静なので国内景気は振るわない。
  - 米作：姤不変。伏した寅財を亥の子孫が暗動して生じ、寅財は飛神に出て長生に入る→豊作、米価低落。
  - 軍事：未済→豫。二爻の子孫が回頭生で干戈なし。伏した亥水官鬼が日冲で暗動→海軍が南洋（午方）で暗に活動、敵は卦に現れず→平穏。

### (37) 軍事
- 【用神】世＝我が国・陣地、応＝敵、子孫＝我が将帥、官鬼＝敵将、財＝兵站、父母＝軍旗・軍艦・汽車・輜重・航空機、兄弟＝伏兵・地雷・潜航艇。
- 【占断の目安】世が旺で応が衰なら我に勝算。応が旺動して世を剋すなら、忍耐して開戦するな。
- 【要点】
  - 五行：水＝河濠、火＝砲銃、金＝鎗剣、木＝橋梁舟車、土＝堡塁。八卦：坎は水戦、離は砲火、艮は山戦など。
  - 子孫が衰・空・墓絶なら無能の将。休囚の官鬼が多くても、旺相の子孫が一つあれば寡で衆を破る。
  - 応の財が休囚空伏なら敵の糧が窮まる。応に子孫が臨み動いて世を生合すれば、敵が講和を求める。
  - 外卦の子孫が応と生合すれば、我が将校に内通者。子孫が官鬼に化して応に情あれば売国奴。
  - 世応が相合して生扶を受ければ和議成立。世応が他の局に三合すれば第三国の斡旋で講和。
- 【九鬼説】★古人にも自分にも軍事の占験がほとんどないので、高島呑象の旧占を借りた。
- 【占験】
  - 明治8年、雲揚艦砲撃事件：未済→晋、世応比和で子孫が回頭生→平和に収まる。高島の「明治10年朝鮮平定」の後言は外れ。
  - 明治27年、旅順攻撃：大壮→夬、子孫が酉の進神で敵将の寅官を剋す→占領は敵国（本宮）の墓絶の日（辰巳）と断じ、22日辰日に占領。
  - 明治28年、講和談判：豫→坤、応の午火が世を生合→実は降伏の申し入れ。出空の午日（4月17日）に講和成立。
  - 大正3年、青島陥落：豊→恒。門人は子孫卯の値日（13日）と断じたが、九鬼は「攻撃中だから既に占領も同然。陥落とは我が突撃を止める日＝卯を冲する酉日」として明日の7日と断じ、的中。

### (38) 身命
- 【用神】世＝自己（代占なら依頼者）、応＝他人・相手。寿命は世だけで見る。財禄は世と財・兄、功名は世と官・子・父、安否は子孫を主に見る。
- 【占断の目安】★身上の安否・財禄・功名・寿命は**別々に占う**。
- 【要点】
  - **財禄**
    - 世・財・子孫が共に傷なく旺相→家運は長く栄える。
    - 世と財が旺でも子孫が傷→先に栄えて後に衰える（子孫は財の源）。
    - 世と子孫が旺で財が弱い→財は多くないが安泰（遺産で暮らす人、高徳で求めずして支給を受ける人）。
    - 世が有気で財に気なし・子孫に気なし→財を蓄えないが大金を扱う（銀行員・番頭）。
    - 世・財・子孫が皆無気→至下の貧民。
    - 世が入墓なら、一生酔ったようで怜悧でない。
  - **安否**
    - 世を剋す爻が禍因。官鬼の剋が最も凶。五行（火は火災、水は溺水など）、六神（玄武は盗賊、白虎は兵禍、螣蛇は変死など）、八卦で禍の種類を見る。
    - 子孫が持世・発動なら、漂流・悪疫・兵乱・重罪の嫌疑にも無事。
    - ★避難の仕方
      - 世が外卦で忌神が内卦→外に出る。世が内卦で忌神が外卦→家に籠る。
      - 避難の方位は、世を生ずる爻の方位。なければ子孫の動爻の方位。
    - 世を生ずる爻は、悪煞・官鬼でも害をしない（悪人も親しい者には恩愛がある）。
  - **功名**
    - 官鬼が主星、父母が才能、兄弟が傷財、子孫が傷官・逸人、財が俸禄。
    - ★子孫が持世して発動すれば、就官の念を断て。
    - 歳星が五爻に臨み官鬼が旺で世を生ずれば、微賎から天下の大権に上る。
  - **寿命**
    - 世が根元。
    - ★**寿命占では元神が静かなのを尚び、発動を嫌う**。動けば一時は有力でも、墓絶・冲の時にかえって疲れる（滋養食を常食していた人がやめると急に衰える。粗食の農夫が長寿なのと同じ）。世を冲剋する爻も静かなのがよい。
    - 世が日月動爻の剋冲を受けても、六冲がなければ病死。六冲・凶煞があれば変死。
    - 致命の病は仇神の五行で見る。
  - **綜合**
    - 子孫持世なら恬淡で道を修める。父母持世なら文筆の人。兄弟持世は財運占では富を許さない。
    - 本命・卦宮の旺衰で身命を断ずるのは大きな誤り。爻象で見る。
  - **家族**
    - 父母・兄弟・妻・子は各一人ずつ分占する。
    - ★妻妾の用神は財。黄金策が応を妻とするのは、一卦で自分と家族を兼占するための便法にすぎない。財を主、応を従とする。
    - 財が両現なら、応に臨む財、日月が臨む財、世が化した財が正妻。財不現で他の爻が財を化出して世を生合すれば再縁の妻。財が旺相で玄武なら多淫、桃花が加われば姦通。
    - ★陽爻を父、陰爻を母とする世間の法は誤り。
    - ★兄弟の人数を五行の生成数で出す法は応験がない（多寡は旺衰で概定するだけ）。
    - ★子の占で、官鬼が子孫に化す・子孫が官鬼に化すのは子なしの兆。
    - ★子孫が子孫に化す象：若い親なら多子、壮年で子ありなら孫多し、老年なら養子（他宮なら異姓、本宮なら血族）。
    - 子の育ちやすさと将来の富貴は分占する（長寿の人が皆富貴ではない）。
- 【占験】
  - 復→頤：財が持世だが、元神の子孫が月破で絶に化す→衣食は困らないが富を成さない。★子孫の絶化を「子なし」と読めば誤り（四男二女あり）。
  - 比→観：世が空でも月合・日の長生・応の財の独発で生じられる→卯年に薬種の暴騰で巨利。★生合あれば空と論じない。
  - 頤不変：財が持世だが休囚・空で助けなし→東奔西走して何も成らず、役夫として従軍し行方知れず。
  - 中孚→節：上爻の官鬼が財を化出して世を剋す（助鬼傷身）→「元神が墓絶の両月は門を出るな」。役所に呼ばれて代人を出したところ、代人が途中で変禍に遭い、本人は免れた。★災禍は避ける道がある。
  - 兌→随：日月と動爻の卯木が世を剋し、世は空で一時逃れている→出空の未月（旧6月）に大難。6月29日、「今日無事」と言った直後に独木舟が転覆して溺死（水に死し木に死す）。
  - 否→遯、比→屯、蒙→臨の三占：随鬼入墓で寿命と確定し、玄武・金の回頭剋・白虎から刀傷を推す→申歳に盗賊に斬殺された。
  - 噬嗑→睽：寅木の応が大剛すぎて今は剋さない→未申月（墓絶）に厄。「6〜7月は東へ避けよ」と告げ、7月8日に東へ避難、28日の大地震を本人だけ免れた。
  - 益→中孚：貸金の取立てに今出るな、辰刻（出空）を過ぎてから行けと引き留めた→渡江の大船4隻が暴風で覆没し、命拾いした。
  - 母の寿：大壮→升。子年に歿すと断じ、30余年後に「母は20余年前の子年に歿、父は健在」と確認。
  - 祖母の寿：帰妹→震。占っている最中に「急死」の報。父母に救いの象ありと見て駆けつけ、痰の閉塞と判断して白生礬の水を注ぐと蘇生し、13年生きた。
  - 子の多少：屯→節。現在4人、後に4人、一人は刑（片目）でかつ生合（俊秀）→片目の子が14歳で大科に及第、のち参政。
  - 陰徳：革→夬で「命に子なし、陰徳を積め」→散財して救済・公共事業に尽くし、午年に二子を得た（婚姻の章）。

### (39) 家宅
- 【用神】父母＝宅舎、世＝本居、応＝神仏廟堂。
- 【占断の目安】父母が旺相で世に臨むか生合すれば吉宅。父母が動いて世を剋す、世の父母が空破墓絶なら災いの家。
- 【要点】
  - ★**修覆や動土は子孫の方位**で行い、官鬼の方位では行わない（官鬼が土を持すればどの方位も不可）。移転は子孫の方位か世を生ずる方位。入居の吉日は世を生ずる日。
  - 官鬼が発動すれば、その方位の場所に禍根がある。用神を生ずる月日、または官鬼を剋す月日に修補する。
  - 官鬼が用神を冲するときの祟の見分け
    - 白虎＝伏屍、玄武＝水怪・盗、螣蛇＝怪異、朱雀＝官非・火災、勾陳＝土神。
    - 水鬼＝溺死の霊・井、木鬼＝縊死・門戸・棟梁、火鬼＝焼死・竈、応の鬼＝その家を恨む者・債主。
    - 官鬼が日月に臨めば正神の祟（幽霊ではない）。
  - 別象（父母で決めかねる時）
    - 外卦＝人、内卦＝宅。二爻＝宅、五爻＝人。
    - 人が宅を剋すのは吉（人が宅を治める）。宅が人を剋すのは凶。
    - 宅爻に合する支が門、冲する支が路。
  - 世が遊魂卦で動けば転居の意。世が駅馬を帯び、遊魂から帰魂に変ずれば、旧宅に戻るのが吉。
  - 六爻分断（参考）：初爻＝井、二爻＝堂奥、三爻＝門・神祠・仏壇、四爻＝戸、五爻＝道・長子、上爻＝棟梁・墻壁・祖霊。

- 【占験】

  - 萃不変：子どもは寅卯の刻、父母は申の刻（卯木の絶、父母の長生）に入宅せよ→17年平安。
