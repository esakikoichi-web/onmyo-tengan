# 『周易裏街道』（上・下）まとめ

仁田丸久 述／東洋書院（上下巻・全約1,200頁）

> 青龍孔一（江﨑孔一）さんの実占用ノートです。ドライブの「周易裏街道(占断の秘訣)上巻・下巻」シートの卦の並びに合わせて、**六十四卦ごとに占断の秘訣**を整理しました。あわせて、**卦をまたいで使える占法の秘訣**、**霊術・潜在意識の秘法**、**開運・金運の秘策**、**測字・夢・方災・人相**、**古事記易説・鬼神論**、**別れ道（秘伝編）**もまとめています。
> 本文に「★」を付けた箇所は、著者が「長年の経験でよく当たる」「秘伝」と明言しているものです。

## 0. 本書について

- **著者**：仁田丸久（明治33年〜昭和48年5月1日没）。本姓は車谷。「仁田」は亡くなった幼馴染の姓で、人のためにする仕事のときに名乗った。本業は神戸の貿易会社勤め。
- **成り立ち**：昭和30年から、神戸・諏訪山房で毎週火曜に行った講義の筆録。はじめはガリ版冊子で配られ、第1〜35輯が周易裏街道の本編（乾〜未済＋雑卦伝）。第36〜42輯の「わかれ道」には、開運秘策・神通路登攀録・鬼神使役法・魔杖・遠隔修法・秘伝秘解が入っている。
- **立場**：易を「霊術の書」として読む。聖書、深層心理（フロイト・ユング）、友清歓真（神道天行居）の古神道、人相、測字、仏典（華厳・般若・涅槃・観無量寿経）、古事記を縦横に引く「八宗兼学」の読み方。
- **全体を貫く二本柱**（ドライブ「基礎」シートの二行そのもの）
  1. **★表が出たら必ず裏も見る**：裏卦、互卦、易位（上下入れ替え）、倒卦、変卦、関連卦を必ず重ねて見る。「得た卦だけで判断せず、関連卦を見ながら判断できて一人前」。
  2. **★易は半分、潜在意識が教えてくれる**：卦を立てる一瞬は誰でも霊能が出ている。その一瞬を延ばし、太極（潜在意識の底）から来るひらめきを言い切れるように修練する。
- **紀藤元之介のあとがき**：「天下の奇書。製本しておいて十年後に精読してごらんなさい」。

## 1. 占断全般の心得

### 1-1 易者の心得（山水蒙＝「易者心得帳」）
- 客は「敵娼（あいかた）」で、最も親しい相手ほど怖い。客は常に占者を試している。
- 理想の易者は蒙二の「**包蒙**」。何でも知りながら知らん顔をし、客の心を見抜きつつ馬鹿になる。上爻の「撃蒙」のように悪いところを洗いざらい言うと、効くが客は離れる。
- **山下出泉**：来るたびに新しい良いものを与えよ。秘伝を抱え込むと新しいものが湧かない。
- 客の型：
  - 初＝義理のしがらみで動けない客。「正法」（法律より大きな道理）で元気づける。
  - 三＝行動派。説教は要らない。知恵を貸せ。
  - 四＝もう手遅れで、気休めに来た。
  - 五＝占者を信頼しているが、一応試している。
- 占者は当てるだけでなく、何かを与えよ（需五「需于酒食」＝今を楽しめ、と気分を変えさせる）。

### 1-2 言い方・態度
- **★明快な活断で腕を見せびらかすな**（客が来なくなる）。婉曲に、相手の潜在意識に届くように言う。
- 当てて驚かそうという功名心があると外れる（加藤大岳・武市岳川も同意見）。八方破れで相手の中に入れば詳しく見える。
- 褒めるばかりでなく少しはくさせ。「あなたは頑固なところがある」が無難。
- 下手な易者はすぐ祟りを言う（客は来なくなる）。
- 啓示を受けても、一般の人に神がかりを感づかれてはいけない。
- 試験が難しいと卦の通りに言って帰したあとで、「どうかこの易が外れて合格しますように」と祈る（夬五の「易者の陸夬」）。
- 時には強く叱ることも必要（睽の信仰の話）。

### 1-3 易の読み方の基本
- **★陽爻の爻辞は積極的に、陰爻の辞は消極的に書かれている**（著者が気づいてから占断が楽になった）。
- **吉凶は根本的には「吉＝陽、凶＝陰」の符号**である。善悪だけで取ると活断できない。例：入れ歯をプラチナにするか金にするか→節二「不出門庭凶」→凶＝陰＝安い方でよい。
- 爻辞の長短にも意味がある。上爻のように長くわけのわからない辞なら、問筮者の話も回りくどい。
- 易は卦を平面でなく、流れ動くものの一コマとして見よ（解二「田獲三狐」の三匹目は元の屯の位置に逃げていた）。
- **小説・探偵小説を読むように卦に向かえ**。どんな難事件も六十四卦のどれかにぴったり当てはまる（オランダ王室の家庭騒動を睽で全部読み解いた例）。
- 周易の作者は驚異の心から出発した。乾で誰も見たことのない龍を出し、最後の未済は小狐の川渡りで終わる。平凡な冬景色にも龍と同じ驚きを覚えられないうちは、まだ易が「未済」。

## 2. 卦をまたいで使える占法の秘訣

| 秘訣 | 内容 |
|---|---|
| ★**応期の秘伝**（目黒玄竜子伝） | 爻を人体に配し、事の来る速さを見る。速い順に、**初＝足**（時がもう向こうから来つつある）→**上＝口**（向こうから声がかかる）→**二＝眼**（目をつけている、少し暇がかかる。内卦離の二・外卦兌の上は特に強い）→**五＝耳**（聞かぬふりで裏では来つつある。病人は裏で治りつつある）→**三＝背**（背を向けている、「まだなかなか」）→**四＝股**（速そうで結局一番遅い）。 |
| ★**変爻で相談内容を当てる**（初代玄竜子） | 上変＝目下の者にされること／五変＝商売・上長・社長（女なら夫）／四変＝物の離れぎわ／三変＝物事の成就・一区切り（恋愛の間違いも多い）／二変＝住居・目下・妻のこと／初変＝足・旅行。 |
| **原筮** | 原＝再。はじめの筮で内卦、再筮で外卦を立てよ（下からへりくだって）。ただし梅花心易・無筮立卦は上卦から取る（答えは上から来る）。 |
| ★**互卦を拡大して見る** | 六爻は粒子の細かいフィルムのようなもので、拡大できる。泰→帰妹→既済→未済と互卦をたどると、六十四卦は結局、乾・坤・既済・未済の四つに帰る。どこから来た卦かを確かめると占考が楽になる。例：帰妹で性病と見ても、互卦が既済なら伝染性でなく遺伝性。 |
| ★**兌と艮の表裏** | 兌が出たら（特に中爻なら）艮にして見る。艮が出たら兌にして見る。師二で「頭株だろう」と見たら、実は妻の病気で炊事洗濯をする女房役だった例。蠱上を失恋の男に得たら、艮の裏の兌＝故郷で縁談が来た例。 |
| ★**「我」の字の卦** | 蒙・訟・観・頤・鼎・旅・中孚・解・益のように爻辞に「我」が出る卦には、本卦・互卦・変卦のどこかに必ず艮がある。そこに目をつけて占考せよ。 |
| ★**上卦に兌／震が立つ卦** | 上卦兌の卦（咸を除く）が出たら「昔盛大な時がありましたな」。上卦震の卦（豊・小過を除く）なら「これから栄えられます」。 |
| ★**上卦が坎の卦の上爻** | 井・蹇・既済・需などの上爻は大体吉と判断してよい。既済上「濡其首」も、成否を問えば「成る」（鳩山首相の訪ソは実現した）。 |
| **陰陽相応でも吉とは限らない** | 時世による（屯五・萃初＝群衆事故）。 |
| **「戸」と「門」** | 前の爻が陽なら「戸」（一枚戸）、陰なら「門」（二枚戸）と書き分けている（随初・節初二）。 |
| ★**否定語の使い分け**（既済二で詳説） | 匪＝感情的な否定（「人でなし」）／勿＝してはいけないが、時にはそうせよ／否＝全く無関係／无＝今はノーだが巡ってイエスもある／亡＝消えてなくなる／弗＝よく似ているが違う（彷彿・仏）。 |
| **「以」「用」の字** | 爻辞にあればその爻は変じやすい（長井金風）。 |
| **失せ人の方角** | 姿を隠そうとする失せ人は裏卦で取る（紀藤元之介『占考要』）。 |
| **三陰三陽の卦** | 泰か既済を解決の標準にせよ。 |
| **五行易の応期** | 日辰で応期を見ると±1日ずれるので「何日前後」と言え。月はぴたりと節入りで変わる。 |
| **七曜を五行に使ってよい** | 全世界の人が使っているものに応験がないはずがない（火曜＝火など）。 |
| ★**卦の取り違え** | 作為なく自然に取り違えて見た卦の方が当たる。易の神がそう見させたのである（无妄の心）。 |
| ★**問題が出る前に浮かぶ卦** | 前触れとして使える。時間に拘泥しない（恒初が浮かんだあとで、専務の相談で恒上が出た）。 |
| **強すぎる時は一つ抜く** | 五行易で用神・月建・日辰がすべて同じ五行のように強すぎる時は、「大過」とみて一つ抜かないと当たらない（地震占で「近江」を抜いて「遠江」と見た）。 |
| ★**目を細めて易経を見る** | 易経の該当卦を開いたら、瞬間的に火の気・水の気（→7-1）をやって目を細めじーっと見る。字が動いて絵に見えてくる（鼎の字が、ベッドの患者を医者が向かい合って診ている絵に見えた＝医者同士の意見の対立を当てた）。「他人に言えないところに本当の秘伝がある」。 |
| **五常と五行** | 木＝仁、金＝義、火＝礼、水＝智、土＝信。兌なら「勇気は良いが激しすぎぬよう」と出処進退の方針に使える。 |
| **易位の考え** | 話しかけても答えない時は、上下を入れ替えた卦（履なら夬）で探りを入れると当たる（古来の秘訣）。 |

## 3. 六十四卦別 占断の秘訣（上経：1 乾為天 〜 30 離為火）

各卦について、【得卦時】（その卦が出たときの判断の要点）、【裏】（裏街道の鍵）、【爻】（爻の要点）の順に並べています。

### (1) 乾為天
- 【得卦時】聖人君子には良いが小人には悪い。表は立派だが内実は火の車（武士は食わねど高楊枝）。「便所のない家の設計図」（見た目はきれいだが実用に向かない）、美しい嘘、羽衣の天女。
  - 初変＝苦労、油断の失敗、失財、住居。
  - 三変＝切羽詰まり。頼まれて世話したのに相手はけろりとしている。
  - 四変＝病気のことを占いたい。
  - 三・四爻＝人位で、三角関係・浮気・中年の恋・寿命・厄（「厄ですなあ」と言えば手応えがある）。
- 【裏】★乾が出たら坤を考え合わせよ。悩む人に「天行健」が出るはずがなく、それは仮象である。裏街道では天雷无妄も考え合わせる（无妄は災＝人の命運占の秘訣）。
- 【年齢】初10代＝生れ出る悩み／二20代＝開墾が報われない／三30代＝とんでもない災難／四40代＝保守退嬰／五50代＝失業／上60代＝ワンマン、命の終わり。
- 【取象】近代ビル（表は石張り、内は人がうようよ＝坤）。
  - 初＝地階のボイラー（見えないが、悪くなると全体に響く）。
  - 三＝油絵（遠目に美しく近くで悪い。椿姫型の女、水難）。
  - 五＝花電車の客、親戚にたかられる、「その女性は金使いが荒い」。
  - 上＝屋上から飛び降りたい誘惑。

### (2) 坤為地
- 【得卦時】牝馬のように素直についていけ。こつこつやれば成就。朋＝大衆で、女は衆となれば強い（米騒動）。内卦は男に対する女の気持、外卦は態度を表す。
- 【爻＝女の一生】
  - 初＝若い女が男を送り出す。外見の目立つ男にひかれる。出直しの時。
  - 二＝女らしい中年の女。見込みあり。
  - 三「含章」＝現実的でけち、蒐集本能。「思い切ってやらせてよい」。
  - 四「括嚢」＝風の中の羽根のように落ち着かない女心。本当のことを言わない。
  - 五「黄裳」＝女房役、なくてはならない鰹節。
  - 上＝男まさり、有名婦人。「其血玄黄」＝陰陽の交わり。
- 【応用】説卦の「山沢通気・雷風相薄・水火相射」を当てれば周易も断易になる（益不変で配卦が正位とことごとく違う→就職不調と断じて的中）。

### (3) 水雷屯
- 【得卦時】職業・地位に不安があり、今の所にいたくない。原因は、上から押さえる本当の親分がいないこと。金さえあればよい時だが、期待した人が案外金を出さない。
- 【爻】
  - 初＝幼い若君。
  - 二＝十年辛抱する忠臣。
  - 三「即鹿无虞」＝既に心は五へ行っている。「同僚に行を共にしない人がいるでしょう」と言うと当たる。止めても行って後悔する。
  - 四＝五の娘で初の許婚。
  - 五＝一時王位に就いた者で、けちで部下を可愛がらず長続きしない。
- 【裏】屯・随・臨・无妄・革は卦辞に元亨利貞があり、初爻はどれも「不肖の子」。

### (4) 山水蒙
- 1-1の「易者心得帳」を参照。蒙の客は子供のようにやんちゃ。互卦坤なので、疑い深く、迷い、奇蹟を求め、けちでしつこい。

### (5) 水天需
- 【得卦時】河止め（前に進めない）。焦っていらいらしている人に「危ないから一寸待て、時が来れば行ける」と言う。頭の中で事実以上に悪く想像し、しょげて下ばかり見ている。
  - 初変（井）＝表面は注意深いが、いざとなると底抜け。産後の肥立ちが悪い。
  - 三＝水難、飲み物・酒に注意。
- 【爻】五「需于酒食」＝今を楽しめ。今の現実が案外良いと指摘して気分転換させよ。
- 【裏】易で性交を最もよく表すのは需（需＝雨・濡）。

### (6) 天水訟
- 【得卦時】「無理を通してはいけない」「上役と意見が合わないだろう」。謀反気を持っている。
  - 二変＝女ならたいてい妊娠（孚＝孕）。
  - 四変＝商売なら値段の食い違いなので、よく調べよ。
  - 相場＝上がると見せてどかんと落とすエアポケット。
  - ★失せ物＝「左右の人を探せ」で当たる。
- 【処方】訟を「頌」に変える（長井金風）。天空の下の大河を思い、争いの小ささを悟ってねぎらい合え。坤＝大釜（六斗四升＝64卦がすべて入る）＝大きなところで物を見よ。

### (7) 地水師
- 【得卦時】平凡平穏な時、やれやれと安心した時にどかんと起こる。「戦時体制の気分で行け」。表面は平穏でも、食うか食われるかが隠れているので真剣勝負で臨む。
  - 小をもって大を兼ねる忙しさ。
  - 出産＝臨月は用心、思わぬことが起こる。子ができるか＝できない。
  - 船積みの商売は損。一心に思いつめる人・発明家。
  - 病＝きつい薬では治らない。ただし長患いは案外起死回生（毒が薬になる）。
  - 事業の悩み、同僚の妬み、居所の不安・移転。「体のこと、病気のことですね」と言える。
- 【雑卦】★師＝憂＝優＝俳優。師が出たら、何かたくらみがあり、プログラムを組んでやっている（人には言わない）。
- 【爻】
  - 初「律」＝厳しい掟だけでなく、悦び（娯楽）を与えよ。
  - 三＝古参で言うことを聞かない。「上役に反抗したら失敗」。身命占でこの爻ならもう死んでいる（霊柩車の象）。
  - 四＝緊張がゆるみ放漫になる。「まだ三年辛抱」。
  - 上＝論功行賞。過去を振り返らないと、最後に破綻する。
- 【裏】二・五は裏卦の天火同人で判断する（尾栄大寛の師五の占例：母の死因、息子の病、知事選落選をいずれも裏の同人で見抜いた）。
- 【象伝】「毒」＝一心不乱に打ち込むこと。ぜんざいに塩＝思いがけない反対物を入れよ。

### (8) 水地比
- 【得卦時】比＝比較。一陽に衆陰が押しかけ、入札のように比べられる。売手過多、値叩き。表面は和やかでも裏で締め上げ合う（「豊富の中の貧困」）。
  - 新しい望みを持つが、まだ口に出していない人。
  - 布団をかぶって寝る形なので、元気が乏しく病身。病は長引く。
  - 一度交わると変わらない付き合い。形だけでも大勢の意見に従え。
  - 地に水をまけば吸い込まれるので、物事は早くしないと駄目。
- 【爻】上だけは坎の水が届かない＝最後に反対者が出る（講演占で比四→一人だけわからない人がいた）。
- 【雑卦】比＝楽＝陰が多い。上下の関係を超えた深いつながり（琴瑟相和す）。

### (9) 風天小畜
- 【得卦時】★客は本当のことを言わず、猫をかぶる（結婚したくないと言う娘ほど内心は良い人を望んでいる）。口裏を読め。
  - 物事は一寸小休止。外から人が入ってもめ事になる。三角関係の問い合わせが多い。
  - 五爻＝尋ね人は女の所に留められ、後に郷里へ帰る例が多い。
  - 舞台は水商売・寺・木の茂った所。
- 【裏】「性的不満」の卦（来知徳：三爻「夫妻反目」、密雲不雨）。客が言えないことを、こちらから指摘せよ。
- 【雑卦】寡＝女心の細かさ、けち。

> 著者は、断食や滝行・山籠りを勧めていません。「俗人のまま、月給取りのまま、寝ながらでもできる方法」に絞って説いています。

### 7-1 ★火の気・水の気の呼吸法（本書の中核）

**第一段（謙の講）：就寝時に毎夜、2週間続ける**
1. 仰向けで深呼吸を2〜3回し、普通の息に戻す。
2. 吸う息とともに、思念を背筋の一番下から背中を伝って頭頂まで上げる。
3. 頭の中で2〜3回、くるくる回す。
4. 吐く息とともに、顔から体の前面を伝って下ろし、臍下丹田から外へ放出する。
5. これを寝入るまで繰り返す。寝入りばなは顕在意識と潜在意識が交代する時で、暗示がよく効く。

- 最初に便秘がとれ、黒い便が出る（便秘があると効かない）。
- 額が固くなったら、合掌して指から出る気で揉みほぐす。
- 効果：卦を立てて占考するときに、ひらめきが出る。「言い切る自信」はこのひらめきから来る。

**第二段（観無量寿経の法）：第一段を3週間続けた後に行う**
1. 吸う息で「背中を火が上昇する」と観想する。
2. 頭頂で一度息を止める。
3. 吐く息で「きらきら光る澄んだ水が、頭頂から前面を流れ下る」と観想する。

- 火水（カミ）＝神。

**秘言を添える形（秘伝秘解）**
- 吸いながら「**心火清明**」と唱え、尾骨から頭へ霊気を上げる。
- 頭の中で2〜3回まわす。
- 吐きながら「**心水清明**」と唱え、胸から腹へ下ろす。
- 数回で気分が鎮まる。

**既済の講での理論**
- 生き＝息。陽で吸い陰で吐く律動が生命の運営である。
- 背骨の中央を火の気が蛇のように巻き上るのを観想する。脊柱下端のクンダリニー（＝乾初九の潜龍）が上昇して脳に達すると、飛龍在天となる＝対象を持たない知覚＝通力、光明遍照十方世界。
- 効果の順：健康になる、心が軽快になる、渇望がなくなる、神通力が出る。

### 7-2 無量光瞑想・息長の法
- **息長（おきなが）の法**：朝、水晶球を左手に載せて昇る朝日を映す。網膜に焼き付けて目を閉じ、丸い形を観想する。その前に長い息で呼吸を整える（長い息をしなければ長生きできない）。
- **無量光瞑想の段階**：
  1. 太陽を凝視し、目を閉じても映るまで。
  2. 水を観想する。
  3. 水を光る氷に変える。
  4. 氷が大地に敷き詰められる。
  5. 透明な瑠璃の大地になる。
  6. 宝石と光線、金の縄の網が張られる（崩れない信念）。
  7. 八つの池の水音が聞こえたら三昧。
  8. 観想する心そのものが仏＝「神になろうとするより、神で居れ」。
- 易も同じ：筮竹をさばく二本の指＝火の気と水の気。易を展開しようとする己の心が太極＝易は中るほかない。

### 7-3 潜在意識への命令法
- ★寝る前に火の気水の気をして、「この問題を解決してくれ」と潜在意識に命令して寝る。翌朝ふと解決が浮かぶ（手紙を易経の該当卦のページに挟んで寝た例、教育論文を一晩で書けた例）。「忙しければ、よく寝よ」。
- **白地手形を信じ切る**：頼んだら「もう達せられた」「もう治った」と思い切る。太極銀行の白地手形は、百万円と書けば百万円、百円と書けば百円。
- **「仁田丸久潜在意識株式会社」**：自分は社長室に座り、社員（潜在意識）が持ってくる願望に承認の判を押して既決箱へ入れる。あとは社員がやる。
- ★**易の名人になる法**：「自分は易の名人である、決して誤断しない」とまず受取りを出しておき、そこから勉強を積む。先人の易の勉強と、この二本立てで必ず成功する。
- ★**天眼通になる最速の法**：半眠半醒で潜在意識が露出している時に、「わしはもともと天眼を持っている、必要に応じていつでも天眼通になる」と叩き込む。

### 7-4 我を観る我（奇魂と話す法）
- 観五・上「観我生」：我を離れ、自分を観るもう一人の自分になる。大己貴神が自分の幸魂・奇魂と対談した（日本書紀）。
- ★困った時、より高い自分から「そんなことでへたばってよいのか、しっかりせい」と話しかける。煩悶の解決になる。悔やんでいる時に、もう一人の自分が「よく考えれば何でもない」と励ます。
- 巽「重巽以申命」：冬の中の春の下萌え。風の便り・虫の知らせは奇魂が働く時。神法道術とは、乾の冬に巽の風を知ること。

### 7-5 弓の心（精義入神）と易の神々との問答
- ヘリゲル『弓と禅』：弓も矢も自分も的も忘れた時に「当たる」（「今のはあなたが当てたのではない」）。易も同じく、易の神と渾然一体となった時に妙占が出る。★易が上手になると、ちょっと馬鹿になる。

- ★**幽人之貞**：自分が神がかりになるのでなく、「幽人」がなる。下から覗いていればよい＝潜在意識にやらせておけ。

### 7-6 霊力保持の法（頤）
- 気を抜いて「朶頤」（下顎をだらりと下げる）になるな。いつも陽実でいよ。
- ★告別式や、ムカデ・毛虫・蛇に出会った時、寒気を感じた時は、ぐっと歯を噛み、親指を内に握り込み、下腹に力を入れよ（虚に陥るな）。
- 便通が良く腹に力の入った時の勝負は勝つ。一か所に気を集中するな（全体に行き渡り、しかも実）。
- 友清歓真「心を虚にし、腹を実すべし」＝頤の極意。

### 7-7 天眼通・透視（普観自在三昧・万法皆空三昧）
- 肉眼は太極の一切智に対する「制限器」である。老眼鏡の比喩：見ているのは眼鏡でなく、奥の視力。★もともと天眼を持っていると知ることが、天眼通になる方法。
- 誰でもある程度やっている：電話の声で相手の顔が見える。卦を立てようと思った途端に卦が浮かぶ（離が浮かび「賢い人ですな」）。
- **透視**：体への執着を断ち、自我が純粋に帰ると、一切の物が霊の働きの邪魔にならない（色即是空）。薄暗がりで画相が見え、「国にその女との結婚を喜ばない人がいるでしょう」と言って的中した例。幻として見えることが多い。

### 7-8 音霊
- 震＝人間の発声と木霊。聖なるものは悪魔と紙一重なので、出入口には音霊が要る（鈴・鐘・気合・喝）。
- 音の夢を見るようにせよ。易に気合を入れて魔を断ち、声なき声を聞け。
- 占例：時計選びで賁五「戔戔」＝シンソン（時計の音）を聞き比べて買った。

### 7-9 西王母・易経の神々
- 繋辞下伝2章の伏羲・神農・黄帝・堯舜は、易経を開けば目の前にいる。その気持で易経を開けば桃源郷に入っている。ひょいと思いついた判断が当たるのは、先人が教えてくれたのを感じ取ったから。
- ★仙書の98%は偽りで、断食や滝行は無駄。

### 7-10 庚申秘説（巽）
- 三尸（上尸＝頭、中尸＝臓、下尸＝足・色欲）が、庚申の夜に司命神へ罪を告げて寿命を縮める。守庚申（徹夜）を7回すれば滅ぶ。甲子・甲寅の日も同様で、当日は肉食・房事を慎む。
- **駆除法**：その日の朝・昼・夕に東向きで水を汲む。日没後に露天に晒し、夜半に「急々如律令」と唱えて飲む。三尸駆除の霊符を天水で朱書きする（桃の木か白絹に）。用が済んだ符は塩を添えて焼いて返す。
- ★本当の虫は心の虫（妬み・疳の虫・腹の虫）で、これを除くのが運の秘訣。
- **天水の作り方**：新しい湯呑かコップを決めておく。日没後1時間を経てから、釣瓶か水道口から直接7〜8分目まで水を入れる。屋外の清い所に置き、翌朝、日光が届く前に収める。晴天の夜に限る。

### 7-11 サムヤマ（既済・通力実行奥義）
- 自分と対象を同一化する力。鼻にすれば芳香、舌には妙味、目には光、耳には妙音が現れる。過去・現在・未来を「永遠の現在」で握る状態。
- 占例：船荷証券の測字で「兵」＝八（艀）→八日出帆だが、一点加えると「六」が取れる→工作して六日に前発行させた。

### 7-12 幻化の秘法と三昧シリーズ
- 幻化相＝心が相手の潜在意識に投影する（円朝の話芸、内弟子が先生の境地を受け取る）。
- ★**ボロ自動車を押す法**（帝網無尽三昧）：希望が実現した有様をありありと想い描くだけでなく、**それを目の前の空間に押し出す**。目を開ければ、相手と自分が目の前の椅子で対談し、相手が喜んで立ち上がって握手する場面が、芝居のように空間にあると思う。
- **三昧の順序**：普観自在（天眼通）→万法皆空（透視）→法如空（幻化）→法性実有（空から有へ帰る＝「如是」）→我性実有（神通自在：自分の体も他の物も、第三者から見るように無差別平等に見る）→帝網無尽（一つの根本を掴めば無尽に増殖する）→秘密荘厳（煩悩即菩提＝純化された煩悩、理屈で割り切れないものが真理）。
- ★**十玄門の学び方**：理屈でなく、十項目を並べてぼんやり眺める。口で説明できなくても「こうだな」とわかった時が、本当にわかった時。
- ★**創作心**：チンパンジーが箱を「斜めにした」ような、経験にないインスピレーションを出す。期待しないで見た映画の方がよいのは、期待感が本質的な理想像を創作するから。部屋にいながら家の前の桜で花見をする練習。
- 「易に『科学的予言』を持ち込むのは堕落」。

### 7-13 その他の秘法
- ★**厠の秘伝**：排便の一瞬は無念無想で、潜在意識が最も強く働く。家相では第一に寝室を頑丈に、次に厠を立派で清浄にする（武田信玄は厠で戦術を練った）。
- **自相法**：朝起きて深呼吸10回、丹田に気を込め、直射日光を避けて鏡で自分の顔を見る。痒くなれば物事の埒が明く。ひりつく・熱っぽいのは凶。陽気が発すれば吉。他人を見る時は、一旦目を閉じてから見ると印象が残る。

- **夢**：目覚めた直後に首を動かさずに想起すれば忘れない。寝る前に「夢を見る」と命じれば、2週間で夢見る人になる。霊夢の徴は、地上数尺を足が浮いて走る夢、知っている場所から全く知らない場所へ出る夢。
- **太極（渾沌）の観想**：天地も父母もない先に、自分の個性と道を構想したものを想え。寝る時に火を吸って太極を観想すると疲れがとれる。易を立てる時も太極を観想せよ。★一休「生れぬ先の父ぞ恋しき」＝精子→光→太陽→無と観想すれば、乱れた心が静まる。
- **三脈法**（守田宝丹『身体保全法』）：左手の親指と人差し指で両顎下の脈、右手で手首の脈を取る。三か所が均等なら一昼夜は身命にかかわらない。乱れれば、凶事の一昼夜前の兆し（津波の前に店員全員の脈が乱れた例）。
- **内出血を止める法**（柔道八段・助永先生）：左手の親指と人差し指の股を左脇腹に当て（親指は背側）、四指の先でみぞおちと臍の間を押さえ、首を下から上へ5〜6回しゃくり上げる。人にする時は、同じ所を押さえながら、右手で背骨の一番上辺りを叩く。
- **霊術の条件**：心身ベストコンディション（腹が減り目、熟睡、快便、心配がないか一時預けにする）。嘘でもよいから初めから信じてかかる。不思議を経験しても人に言わない。偉いところを見せようと思わない。
- ★**霊術には火と燃える情熱が絶対必要**。青白い幽鬼の道を歩むな。
- ★**友清歓真の戒め「神通はありてよし、なくてよし」**：慢心するな（塚原卜伝は荒馬を遠回りして避けた）。自分の都合で無理に雨を降らすようなことはしない。無理は必ずどこかに出るので、自然に沿ってそれを助けよ。

## 8. 偶然・幸福をつかむ法（開運秘策）

### 8-1 運の正体（わかれ道一「易より見る運の掴み方」）
- ★易者自身がまず幸福にならなければ、他人の運命を指導する資格はない。
- 運は、打者が投げられた球を待って打つものではない。偶然的なものである。ショーペンハウアー「偶然は運命の先行形式」。一度あることは二度ある（偶然の継続性）。
- 偶＝陰＝坤＝現実。**偶然は「場所（方）」と「時」の遭遇で起こる**（古事記の「この時しも」は必ず偶然を書く＝須佐之男が鳥髪に降り、箸が流れてくる）。
- ★**困は偶然が旺相する卦**：明日の手形を落とすような「今日只今」に一心不乱の時に、偶然の助けが来る。**運は今、ここにある**（過去の蓄積や未来の予見ではつかまらない）。
- 益三「益之用凶事」：凶事という偶然を足場に、限界以上の運が生まれる。
- 姤の「羸豕」（ただの豚）を天が包む：平凡な出来事を、驚異をもって迎えよ。★計画の途中の邪魔こそ大切で、気軽に取り組み、計画変更を平気にする。
- アリストテレスの二つの偶然：アウトマトン（chance、意図なく瓢箪から駒）＝震の主。テュケー（fortune、意図して動く中での思わぬ助け）＝震の陽に乗る陰＝**福＝復**。

### 8-2 偶然を構える（咸）
- 持ち物は持ち主の放射を吸収して引き合う。本当にやりたいと思ったことは、偶然の形で必ずやっている（本好きに珍本が来る）。
- 偶然を素直に受け取れば、次の偶然を構えられる。
- ★**瑞兆は重なる**：吉事にこそ応用せよ。

### 8-3 幸福を追いかけさせる法（遯）・易の現像
- 幸福を追いかけず、**頭の中で現像しておいて、さっと身を引く**（恋も追えば逃げる）。
- ★**易の現像**：判断を出したら、静かな所で心の中で現像液をかけてみる＝反省して上達する（ボケや二重写しを知る）。幸福を現像すれば幸福が、恐怖を現像すれば恐怖が現実化する。

### 8-4 ★幸福な偶然の実習（恒）
- 寝る時に火の気水の気をし、うとうとした時に「明日○月○日、自分は精神的にも物質的にも肉体的にもとても幸福だ」と決めてしまう（嘘でもよい）。
- 暗剣殺の日こそやれ。
- 何があっても良い方に解釈し、神のおかげと感謝する。心配は、幸福へ引っ張っていく案内係である。
- **算盤に合わないこと**：他人に親切を与えよ（タクシーで釣りは要らない、席を譲る、収益の1/10を寄付する＝神に返す）。
- ★**生まれた曜日**：物事を始める日は自分の生まれた曜日を選び、完成させる日は生まれた曜日を避ける（著者自身の実験でうまく行く）。

## 9. 金運・商売の秘策

### 9-1 ★損・十朋之亀の貨殖策
- **一日一損**：仕事がなくていらいらしていた貿易商に「一日一損せよ」→電報代やガソリン代を惜しむいらいらが治り、翌日から商売が来た。
- 損は全部でなく、三分の一でよい（「三人行けば一人を損す」）。儲けるための損は「二簋」（簡素）で済ませよ。
- 初「酌損之」：**金銭を散らしても、富を散らすな**。四「損其疾」：どうせ損するなら早く（ぐずぐずするとけちと言われ、金が死ぬ）。
- 損の仕方：サービスより支払いを一日も早く（信用が増す）。支払いの順序は、こちらが払わねば向こうが困る所を先に。馴染みの出入り商人の品は少々高くても買う。
- 世間の要求をしっかり据えて、そこへ損するから儲かる（デュポンの研究費、フォードの寄付）。金は世間から預かっている（「これだけ持っている」と思った時が危ない）。
- 五「十朋之亀」：世間を仇とせず友とする時に金儲けができる。無形の資本＝十の亀（筮亀＝運命学、摂亀＝神の巡り合わせ、水亀火亀＝火の気水の気、霊亀＝心自体）。
- 大象「懲忿窒欲」：かっとなる怒りと、執念深い欲を塞げ。山沢通気のすうっとした気持でないと儲からない。
- 解説で引用されている「儲けるには夫婦が性的に円満であること」もこの講にある。

### 9-2 ★萃＝商売繁盛の秘密
- 祭・オアシス・招き猫（兌のマスコットで坤の群衆を呼ぶ）。
- 大衆の扱い：
  - 初＝右翼（最後尾で一番騒ぐが、一握りであやせば笑いになる）。
  - 二＝主流派（公平な世論）で、これを掴め。簡素でまじめな祭（禴）。
  - 三＝左翼（不平の徒）は気にするな。
