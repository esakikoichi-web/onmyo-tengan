# 『周易講義』まとめ

根本通明 述／星文館（大正10年初版・昭和4年第五版、全944頁）

> 青龍孔一（江﨑孔一）さんの実占用ノートです。『周易裏街道』まとめと同じ形で、**六十四卦ごとの卦意と爻の要点**、**卦をまたいで使える読法の秘訣**、**雑卦伝の即断**、**八卦の象**、**根本流の筮法（三十六変）** を整理しました。
> - 「★」は、根本が特に強調している点、または通説と違う根本独自の説です。
> - 本書は占断書ではなく、易経の講義（経学）です。そのため各卦の【占断の目安】は、根本の卦意を実占向けに引き直した**まとめ役による要約**です。【卦意】【爻】【根本説】は本文に拠っています。

## 0. 本書について

- **著者**：根本通明（文学博士、東京帝国大学教授）。清朝考証学の流れをくむ漢学者で、明治を代表する易学者。
- **成り立ち**：帝大教授のかたわら、私塾で初学者向けに行った講義の速記。
  - 凡例は大正元年、子の根本通徳による。纂修は門人の九鬼盛隆。
  - 速記なので、重複や聞き誤りがあると断っている。
  - 口語（カタカナ交じり）で、実際に筮竹を操作しながら講じた箇所もある。
- **底本**：唐・李鼎祚『周易集解』（李氏易伝）。朱子『本義』系の通行本とは字句が違う所が多い。★「後世本は誤り、古本が正しい」という校訂が随所にある。
- **立場**：易は**象**であり、孔子の十翼に拠って読む。
  - 邵雍の先天図や朱子の性理学は、易を外れたものとして退ける。
  - 論語・孟子・史記・左伝・国語・書経・礼記を縦横に引く。神功皇后や三種の神器など、日本の事例も交える。
- **全体を貫く三本柱**
  1. ★**乾坤往来**：どの卦も、乾と坤の爻の入れ替わりとして読む。
     - 入れ替わるのは、乾の二と坤の五、乾の四と坤の初、乾の上と坤の三。
     - 入れ替わりが済むと**水火既済**になり、万物が各々宜しきを得る。
  2. ★**五爻は必ず天子、二爻は必ず臣**：皇統一系。
     - 乾・震（龍・長男）は皇太子を表す。
     - 革命は「已むを得ぬ時の戒め」で、臣が君を伐つことは肯定しない。
  3. ★**易は行いの書**：吉凶は天から降るのではなく、人の行いの得失から生じる。
     - 悔いて改めれば吉、改めなければ吝から凶へ向かう。
     - 易の道は「**懼れる**」の一事に尽きる。

## 1. 占断全般の心得

### 1-1 易に向かう心構え
- ★**易は用いる人しだい**（神而明之存乎其人）。
  - 心を洗い清め、精神に誠がなければ、易は用をなさない。
  - 至精とは、米の皮を剥いた純粋さのこと。私欲の垢を除けば、天から受けた神霊が働く。
- ★**幾を知るのは無欲から**（知幾其神乎）。五年十年後に来るものは、今すでに微かに動いている。欲があると迷って見えない。
- **初筮は告ぐ、再三は瀆す**（蒙）。誠のない再三の問いには答えない。
- **易は常に座右に置く書**（不可遠）。言う前、行う前に易に相談する（擬之而後言、議之而後動）。易を傍に置けば、父母が付き添っているのと同じ。
- **易の本旨は逆数**。過ぎたことより、これから来ることを予め知るのが易である（数往者順、知来者逆）。

### 1-2 吉凶・悔吝の読み方
- **吉凶は失得の象**。行いが正しければ吉、不正なら凶。
- ★**悔と吝の分かれ目**
  - 悔＝憂えて改める → 吉へ向かう。
  - 吝＝安楽に安んじて改めかねる → 凶へ向かう。
  - 易に「悔」の字が多いのは、悔いて改めることを貴ぶからである。
- **介**（憂悔吝者存乎介）：介＝界＝吉凶の分かれ目。ここで優柔不断になってはいけない。
- **无咎は、よく過ちを補うこと**。
- **危うしと思えば平らかに、易しと思えば傾く**（危者使平、易者使傾）。卦辞が危うい言葉（「虎の尾を履む」など）でも、懼れて慎めば無事に済む。

### 1-3 爻位の原則
- **二は誉れ多く、四は懼れ多い**。二は君から離れて中を得ているが、四は君に近い。
- **三は凶多く、五は功多い**。貴賤の等級による。
- **初は知り難く、上は知り易い**。初爻の辞をよく見て、順に上へ推していけ。
- **陰陽が相応ずれば取り合い、陽と陽なら争う**（遠近相取而悔吝生）。二と五は離れていても、応ずれば近い。
- **原始要終**：始めを原ね、終わりまで遂げることが易の本質である。

## 2. 卦をまたいで使える読法の秘訣

| 秘訣 | 内容 |
|---|---|
| ★**乾坤往来で卦の由来を見る** | どの卦も、乾坤の爻の入れ替えで生じたものと見る。例：訟は需の五が下って二に来たもの、損は泰の三と上の交換、益は否の四と初の交換、咸は否の三と上の交換、恒は泰の初と四の交換、晋は明夷の二が五へ進んだもの。どこから来た卦かを見れば、卦意がはっきりする。 |
| ★**互体・約象で拡大して見る** | 二三四爻が互体、三四五爻が約象（京房）。本卦の二卦に互体の二卦を加えて四卦、裏（伏卦）まで見て六卦。これで存亡吉凶を推す（非其中爻不備）。 |
| **錯・綜** | 錯＝陰陽を反転、綜＝上下を顛倒（来知徳）。例：噬嗑の錯は井、綜は賁。参伍以変＝一人の片言でなく、三人・五人に尋ねるように、何通りにも照らし合わせる。 |
| ★**五爻は必ず天子、二爻は臣** | どの卦でも同じ。五を伯夷・周公・臣下の極と読む古今の注は誤り（遯・升・旅の各項）。 |
| ★**既済が理想形** | 六爻すべてが正位にある。陽位に陰、陰位に陽の爻は「位不当」で、戒めの言葉が付く。 |
| **陽卦・陰卦** | 震・坎・艮は陽卦で一君二民＝君子の道。巽・離・兌は陰卦で二君一民＝小人の道。少ない方の爻が主になる。 |
| ★**五爻が陰の卦** | 柔弱な天子（臨・豫・大有・睽・晋など）。賢臣（二）や大臣（四）を用いれば吉、権臣に握られれば危うい、という構図で読む。 |
| ★**君側の奸** | 兌（巧言令色・虎）や巽（近利市三倍）の主爻は、欲深い大臣や佞人として出ることが多い（履三・夬上・益上・巽上・兌三）。 |
| **十二消息** | 復（十一月）、臨（十二月）、泰（正月）、大壮（二月）、夬（三月）、乾（四月）、姤（五月）、遯（六月）、否（七月）、観（八月）、剥（九月）、坤（十月）。季節と盛衰の時を読む。 |
| **七日来復** | 陽が尽きて七つ目に戻ってくる。失物・離反は「追うな、七日で戻る」（震二・既済二）。 |
| **十年は坤の数** | 十年経っても回復しない、十年待て（屯二・復上）。 |
| **三十年で世が一変** | 泰・否の転換、既済四「繻有衣袽」。世＝三十（十が三つ）。 |
| **甲・庚の日** | 先甲三日後甲三日（蠱）＝始めを改める。先庚三日後庚三日（巽）＝根本は変えず、弊だけを改める。 |
| **戸と門** | 節初「戸庭」、節二「門庭」。互体の震は出る、約象の艮は止まる、で出処の時を見る。 |
| **陰陽不当位は戒め** | 位不当の爻には、たいてい「厲」「吝」の戒めが付く。 |

## 3. 六十四卦別 卦意と爻の要点（上経：1 乾為天 〜 30 離為火）

各卦を、【卦意】（卦の意味）、【占断の目安】（実占での読み方、まとめ役による）、【爻】（爻の要点）、【根本説】（独自の読み・校訂）の順に並べています。

### (1) 乾為天
- 【卦意】元亨利貞＝春夏秋冬＝仁礼義智。乾が二つ重なる＝今日の天が終わって明日の天が始まる＝天子が終われば皇太子が継ぐ。
- 【占断の目安】
  - 休まず勉強し続ける時（天行健、自強不息）。
  - 高位にあっても驕れば、輔佐を失う。
  - 物事は段階を踏んで上がる。
- 【爻＝皇太子の成長】
  - 初「潜龍勿用」＝学問に専念し、まだ手を出さない。
  - 二「見龍在田」＝学徳が世に現れる。
  - 三「終日乾乾夕惕若」＝一日を夜に反省し、翌日さらに励む。
  - 四「或躍在淵」＝天子の側で祭祀の代行や大元帥を務めつつ、賢人の下に身を置く。
  - 五「飛龍在天」＝即位。
  - 上「亢龍有悔」＝知進而不知退。
  - 用九「群龍无首」＝尊くなるほど身を下す。
- 【根本説】
  - ★乾を革命の卦とする説（干宝ら）は「逆賊の説」。
  - 文言「不易乎世」の「乎」は衍字。「知終終之可与存義」は「可与言幾」と対句（後世本は「与」脱落）。
  - 「其唯聖人乎」の重出を削る朱子らは誤り。
  - 「与時偕極」の極＝中。

### (2) 坤為地
- 【卦意】牝馬之貞＝臣・妻の道。
  - 先迷後得主＝君より先に立てば迷い、命を承けて後から行えば得る。
  - 西南得朋（在野で同門と学ぶ）、東北喪朋（出仕したら私党を捨てる）。朋は陰、友は陽。
- 【占断の目安】
  - 自分から先に立たず、主に従えば得る。
  - 小さな悪の芽を早く摘め。
  - 在野の時は仲間と学び、表に出たら私情を捨てよ。
- 【爻】
  - 初「履霜堅冰至」＝仕え始めの小さな邪心が逆賊に至る。★悪は芽のうちに。
  - 二「直方大」＝学ばずして利あり。
  - 三「含章可貞」＝学徳を含んで誇らない。君が始め、臣が終える。
  - 四「括嚢」＝無道の世では口を括って名を求めない。
  - 五「黄裳元吉」＝皇后。
  - 上「龍戦于野其血玄黄」＝半ば天子のように振る舞う臣は必ず敗れる。
- 【根本説】
  - ★五を舜・周公の摂政とする鄭玄説は誤り。
  - 「為其兼於陽也」は「兼」が正しく、「嫌」は誤り。
  - 積善之家必有余慶は、坤の下に乾が伏在する＝子孫繁昌の意。

### (3) 水雷屯
- 【卦意】天地開闢の直後で、腕力の世。険難に進めないので、徳ある侯を立てよ。
- 【占断の目安】
  - 物事の始めで難渋する。無理に従わせず、中心となる人物を立てよ。
  - 縁談は時が定まるまで待て（十年乃字）。
- 【爻】
  - 初「磐桓、利建侯」＝動かないが、侯となるべき人。
  - 二「女子貞不字十年乃字」。
  - 三「即鹿无虞」＝案内なく深山に入る暴進（鹿＝天子の位）。
  - 四＝初に往けば吉。
  - 五「屯其膏」＝恩沢を惜しむ。★項羽の「婦人之仁」（印を渡し惜しむ）と高祖の寛仁の対比。
  - 上「泣血漣如」＝気力を奮え。
- 【根本説】「雷雨之動満形」が正しく、「満盈」は誤り。

### (4) 山水蒙
- 【卦意】師を立てる卦。蒙＝天から受けた性の善が邪に覆われた状態。
  - 匪我求童蒙、童蒙求我＝教えは押し売りしない。求める誠があって初めて教える。
- 【占断の目安】
  - 学ぶ・教わる事は、求める側の誠しだい。
  - 同じことを何度も占うのは瀆す。
  - 子弟の教育は幼少から厳しく。
- 【爻】
  - 初「利用刑人」＝幼少から厳格に調える。放任は吝。
  - 二「包蒙、納婦吉」＝女子の教育（班昭）。
  - 三「見金夫不有躬」＝財に靡く。
  - 四「困蒙」。
  - 五「童蒙吉」＝皇太子が北面して学ぶ。
  - 上「撃蒙、利禦寇」＝欲は我が身の寇。起こった初めに禦げ。
- 【根本説】★天子も師には北面する。

### (5) 水天需
- 【卦意】需＝須＝待つ。下の乾は天徳ある賢人三人、九五は明君、六四は悪い大臣。互いに時を待つ。
- 【占断の目安】
  - 待て。暴虎馮河をせず、忍耐して時を待つ。
  - 大事の前は形を見せず、心身を養え（飲食宴楽）。
- 【爻】
  - 初「需于郊」。
  - 二「需于沙、小有言」＝譏られても動かない。
  - 三「需于泥、致寇至」＝自ら禍を招く。
  - 四「需于血」＝悪大臣が赤心で降る。
  - 五「需于酒食」＝賢人を厚遇。
  - 上「不速之客三人来、敬之終吉」＝招かざる客を敬え。

### (6) 天水訟
- 【卦意】飲食を求めれば争いが起こる（多くは財の争い）。天は昇り、水は降って違う方へ行く。
- 【占断の目安】
  - 争いは中途で止めれば吉、押し通せば凶（中吉終凶）。
  - 誰が聞いても尤もな時だけ起こせ。
  - 事の始めによく考えよ。
- 【爻】
  - 初「不永所事」＝小言程度で止める。
  - 二「不克訟、帰而逋」＝民を煽って自国の君を外国に訴えても勝てない。★左伝の衛の元咺（周王は「臣の訟えで君を殺せない」と拒否）と甯武子。
  - 三「食旧徳」＝先祖以来の禄を思う。
  - 四「復即命」。
  - 五「訟元吉」＝中正な裁き。
  - 上「或錫之鞶帯、終朝三褫之」＝勝って賜った服を見せびらかす。
- 【根本説】褫＝拕（紳を垂らす）。

### (7) 地水師
- 【卦意】正義の戦。丈人＝長子＝皇太子が元帥。以此毒天下＝毒は治める（薬で病を攻める）。
- 【占断の目安】
  - 大勢を動かす事は、大義名分と人の和が先。
  - 血気の若手に任せれば失敗する。
  - 小人の功は賞で報い、地位は与えない。
- 【爻】
  - 初「師出以律」＝出陣の際に律で軍の和・不和を聴く。
  - 二「在師中吉、王三錫命」。
  - 三「師或輿尸」＝功を焦って大敗。
  - 四「左次」＝退いて陣を全うする。
  - 五「長子帥師、弟子輿尸」。
  - 上「開国承家、小人勿用」。
- 【根本説】「丈人」が正しく、子夏伝の「大人」は誤り。

### (8) 水地比
- 【卦意】水が地に浸み込んで離れない＝君と民の密着。★皇統一系を含む卦。
- 【占断の目安】
  - 親しみ、協力の時。早く加われ、遅れる者は凶（後夫凶）。
  - 来る者は拒まず、去る者は追わない。
- 【爻】
  - 初「有孚盈缶」。
  - 二「比之自内」。
  - 三「比之匪人」。
  - 四「外比之」。
  - 五「顕比、王用三駆失前禽」＝逃げる禽は追わない。邑人は夜も門を閉じない。
  - 上「比之无首凶」。
- 【根本説】★蒙の「初筮」と比の「原筮」は、十八変で内卦、さらに十八変で外卦を得ることを指す（→第9章 筮法）。

### (9) 風天小畜
- 【卦意】六四の大臣が、誠で君を育てて明君にする（大畜はその逆で、君が臣を育てる）。
  - 密雲不雨自我西郊＝陰だけの雲で、雨にならない。
- 【占断の目安】
  - 諫言より至誠で動かせ。
  - 事は小さく止められ、まだ雨（成果）にならない。
  - 力が満ちそうな時は退け。
- 【爻】
  - 初「復自道」＝言行に出る前に立ち返る。
  - 二「牽復」。
  - 三「輿説輻、夫妻反目」＝家を正せない者は天下を治められない。
  - 四「有孚、血去惕出」＝★万世の忠臣の手本。
  - 五「有孚攣如」。
  - 上「月幾望、君子征凶」＝大臣の力が満月に近づけば退け（周公旦の流言）。

### (10) 天沢履
- 【卦意】下の兌は虎＝巧言令色の大臣で、乾（天子）を後ろから咥えようとする。★天子が旋って虎の尾を履めば咥えられない。
- 【占断の目安】
  - 危うい相手の後ろを取れ。
  - 上下の分をはっきりさせよ。
  - 質朴に自分の道を行け。
- 【爻】
  - 初「素履」。
  - 二「履道坦坦、幽人貞吉」。
  - 三「眇能視跛能履、武人為于大君」＝乱臣。
  - 四「履虎尾愬愬終吉」。
  - 五「夬履」。
  - 上「視履考祥、其旋元吉」。
- 【根本説】★「旋る」は古今の注が知らない点。旋れば沢天夬になり、大臣の罪を王庭で揚げる。韓非子揚権篇「虎随其後」。

### (11) 地天泰
- 【卦意】泰＝滑らかに流通する。天が降り地が昇って上下が交わる。正月の卦。
- 【占断の目安】
  - 通じる、交わる、協力の時。
  - ただし太平は必ず傾く（无平不陂）。
  - 賢人を抜擢すれば同類が集まる。
- 【爻】

## 9. 根本流の筮法

### 9-1 ★三十六変筮法（繋辞上伝「大衍之数」の講義で実演）

**考え方**
- 天地の数は55。筮法は暦に則る。
- 55本から気盈の5日分を除いて50（大衍）とし、さらに1本を除いて49本を用いる。

**手順**
1. 49本の上下を転倒させて持つ（易は逆数だから）。中分して、掛具（刻）の左右に置く（分二以象両）。
2. 右から1本を抜いて中央に掛ける（掛一以象三）。
3. 左右それぞれを4本ずつ数える（揲四以象四時）。
4. 余りと中央の1本を、第一の刻に置く（帰奇於扐以象閏）。
5. 左右を合わせて再び中分し、同様にして第二の刻へ。これを**6回**行い、第一〜第六の刻を得る。
6. 第四を第一に、第五を第二に、第六を第三に合わせる（初と四、二と五、三と六が応ずる）。
7. 合わせた本数を4本ずつ数える。**8本＝両地（陰）、12本＝参天（陽）、16本＝四時（陰）**。
8. 三組のうち**少ない方が主**になって、一爻が決まる。
9. 一爻に6変 → 内卦で18変 → 六爻で**36変**。

**十八変説への批判**
- ★朱子の十八変（一爻3変）では、初と四などが応じない。
- 毛奇齢も、36変とは言い切れなかった。
- この法は日本に伝わって、中国には残っていない。

### 9-2 ★動爻の求め方＝「艮之八」論（連山・帰蔵）

**問題**
- 左伝襄公九年、穆姜の筮「遇艮之八」は、漢魏唐宋の誰も解けなかった。
- 「之く」は変である（大有之乾、師之臨）。
- 山本北山とその門人（朝川善庵ほか）の「不変の占」説は誤り。

**連山の法（艮之八）**
1. 36変で六爻を布いた後、さらに分掛揲扐して、初爻から順に動爻を求める。九を得ればその爻が動く。
2. 六爻すべて動かなければ、卦を顛倒して震とし、上六で第7数、六五で第8数を起こす。
3. 第8数で動けば、上卦が兌になって随となる（穆姜の「是謂艮之随」）。
4. 艮の六爻は両山が連なるので「連山」。

**帰蔵の法（国語 晋語「貞屯悔豫皆八」）**
1. 屯を布いた後、初爻から動爻を求める。
2. 動かなければ、外卦坎と内卦震を入れ替えて解とし、第8数で動爻を得て豫となる。

- **「八」の意味**：動爻を求めて、第8数で変を得ること。
